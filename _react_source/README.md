# Learnora Learning Platform

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for production

```bash
npm run build
```

## Included working interactions

- Responsive navigation menu
- Smooth scrolling navigation
- Course search
- Course filtering
- Login/register demo modal
- Form validation
- Dashboard task checkboxes
- Course and pricing CTA buttons
- Reduced-motion accessibility support

This is a frontend demo. Authentication is simulated locally and does not connect to a database.
